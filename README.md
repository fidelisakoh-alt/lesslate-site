# LessLate website

Public website for [lesslate.app](https://lesslate.app), including the LessLate support and privacy pages.

## Security and privacy

- Static HTML and CSS only
- No JavaScript
- No forms
- No analytics, advertising or tracking
- No passwords, API keys, signing files or app source code

The iOS application belongs in its separate private repository.

## Public URLs

- Support: `https://lesslate.app/support/`
- Privacy: `https://lesslate.app/privacy/`
